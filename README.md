 NEST: A Nursing Education Scholarly Thesis Repository System

Project Description

NEST (Nursing Education Scholarly Thesis Repository System) is a digital repository system developed for undergraduate nursing students of Bicol University College of Nursing.

The system aims to address the problems associated with the manual physical storage of undergraduate nursing theses, slow search and retrieval, and the absence of a centralized digital repository.

NEST provides a centralized and organized platform for managing and accessing approved undergraduate nursing theses. It supports different users, including nursing students, faculty/advisers, alumni, and administrators.

Key Features

- Centralized digital thesis repository
- Thesis search and retrieval
- Role-based access for different users
- Thesis browsing and viewing
- Organized storage of thesis records
- Access and activity logging
- Administrative management

Target Users

- Nursing Students
- Faculty/Advisers
- Alumni
- Administrators

Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend/API:** PHP (Laravel)
- **Database:** MySQL
- **Architecture:** Layered (N-tier) Architecture

## Project Scope

NEST focuses on providing a centralized and organized repository for undergraduate nursing theses of the Bicol University College of Nursing.
