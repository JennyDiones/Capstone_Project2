NEST: A Nursing Education Scholarly Thesis Repository System

NEST is a digital repository system developed for undergraduate nursing students of Bicol University College of Nursing. It addresses manual thesis storage, slow search and retrieval, and the lack of a centralized digital repository.

Target Users
- Nursing Students
- Faculty/Advisers
- Alumni
- Administrators

Technology Stack
- HTML5, CSS3, JavaScript, Bootstrap
- PHP (Laravel)
- MySQL
- Layered (N-tier) Architecture
